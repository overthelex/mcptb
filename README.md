<h1 align="center">Thunderbird MCP Server</h1>

<p align="center">MCP server for managing email via Thunderbird — send, read, search, and organize emails from CLI.</p>

---

## Features

- Send emails with CC/BCC
- List and read emails
- Search emails
- Manage folders and contacts
- Works with Claude Code via MCP protocol

## Quick Start

```bash
docker-compose up
```
